## 〇、前置条件检查

### 1. 虚拟机的 mongod 必须对外监听

Compass 装在宿主机，要连虚拟机的 27017，所以 mongod 必须监听 `0.0.0.0`：

```bash
# 在虚拟机里检查
ss -lntp | grep 27017
```

**必须是这一行**：
```
LISTEN 0 4096 0.0.0.0:27017 0.0.0.0:*
```

如果是 `127.0.0.1:27017`，宿主机连不上，需要重启：

```bash
sudo pkill mongod
sleep 2
sudo mongod --dbpath /export/servers/mongodb/data \
            --port 27017 \
            --logpath /export/servers/mongodb/log/mongod.log \
            --fork --auth --bind_ip_all
```

> 关键参数是 `--bind_ip_all`，不加的话只监听本地回环。

### 2. 防火墙放行

```bash
sudo firewall-cmd --permanent --add-port=27017/tcp
sudo firewall-cmd --reload
sudo firewall-cmd --list-ports
```

**期望输出**：`27017/tcp`

### 3. 宿主机测试连通

在**宿主机**（Windows）上执行：

```powershell
Test-NetConnection -ComputerName 192.168.121.128 -Port 27017
```

**期望**：`TcpTestSucceeded : True`

### 操作步骤

**第 1 步：打开 New Connection**

Compass 启动后是欢迎页，点以下任一按钮：

- 左上角 **`+ Add new connection`**
- 或中间的 **`+ Add new connection`** 大按钮

**第 2 步：选 New Connection**

出现三个选项，选 **`New Connection`**：

| 选项 | 说明 |
|---|---|
| `Recent` | 最近连接（空的） |
| **`New Connection`** ← 选这个 | 手动填连接串 |
| `Favorites` | 收藏的连接 |

**第 3 步：填 URI**

顶部 URI 框默认是 `mongodb://localhost:27017/`，**全选删掉**，粘贴：

```
mongodb://libWriter:Lab%402026@192.168.121.128:27017/library?authSource=library
```

确认 **`Edit Connection String` 开关是开启的**（蓝色），URI 框才可编辑。

- **Name** 输入框：`library-nosql01`

**第 5 步：连接**

点右下角 **`Save & Connect`**（最右边的深绿色按钮），一步完成保存+连接。

## 常见问题

### Q1：Compass 连不上，报 timeout / connection refused

**检查虚拟机**：

```bash
ss -lntp | grep 27017
```

必须是 `0.0.0.0:27017`，不是 `127.0.0.1:27017`。

**检查防火墙**：

```bash
sudo firewall-cmd --list-ports
```

必须包含 `27017/tcp`。

**检查宿主机连通**：

```powershell
Test-NetConnection -ComputerName 192.168.121.128 -Port 27017
```

---

### Q2：报 `Authentication failed`

三个原因，按顺序排查：

1. **密码没编码** —— `Lab@2026` 要写成 `Lab%402026`
2. **authSource 写错** —— `libWriter` 是 library 库的账号，不能写 `admin`
3. **用户名拼错** —— `libWriter` 大小写敏感

---

### Q3：左侧看不到视图和时序标记

Compass 1.53 用**图标**代替文字标记：
- 👁 眼睛 = 视图
- 📈 波形线 = 时间序列

如果图标也没显示，可能是窗口太窄。拉宽左侧栏试试。

---

### Q4：找不到 `Export Full Collection`

新版本 Compass 的 `EXPORT DATA` 下拉里可能只有：
- `Export Full Collection`
- `Export Query Results`

两个都能用。选 `Export Query Results` 时，Filter 保持 `{}` 即可导出全部。

---

### Q5：Aggregations 里 `$group` 报错

检查 JSON 格式：
- 字段名有没有加引号（`_id` 必须加）
- 括号是否配对
- `$sum: 1` 的 1 是数字不是字符串

正确写法：

```javascript
{
  _id: "$category",
  count: {$sum: 1}
}
```

---

### Q6：导出的 JSON 打开是乱码

Compass 默认导出 UTF-8。如果记事本显示乱码，用 VS Code 或 Notepad++ 打开，或者记事本里「另存为」时选 UTF-8 编码。
