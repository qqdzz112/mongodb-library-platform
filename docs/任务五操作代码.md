## 二、mongodb_connect.py —— 连接模块（ST-5.2）

### 关键代码

```python
from pymongo import MongoClient
from urllib.parse import quote_plus

# 连接参数集中定义（任务书 ST-5.2 要求）
MONGO_HOST = "127.0.0.1"
MONGO_PORT = 27017
MONGO_USER = "libWriter"
MONGO_PASSWORD = "Lab@2026"
AUTH_DB = "library"        # ← 注意！libWriter 建在 library 库
DB_NAME = "library"

USE_AUTH = True            # 启用 --auth 后必须为 True

if USE_AUTH:
    # 密码里的 @ 是 URI 保留字符，必须 URL 编码成 %40
    _user = quote_plus(MONGO_USER)
    _pwd = quote_plus(MONGO_PASSWORD)
    URI = (
        f"mongodb://{_user}:{_pwd}@{MONGO_HOST}:{MONGO_PORT}/{DB_NAME}"
        f"?authSource={AUTH_DB}"
    )
else:
    URI = f"mongodb://{MONGO_HOST}:{MONGO_PORT}/"


class MongoDBConnect:
    _client = None

    @staticmethod
    def get_connect(uri=URI):
        if MongoDBConnect._client is None:
            MongoDBConnect._client = MongoClient(uri, serverSelectionTimeoutMS=5000)
        return MongoDBConnect._client

    @staticmethod
    def get_database(db_name=DB_NAME):
        return MongoDBConnect.get_connect()[db_name]

    @staticmethod
    def ping():
        try:
            MongoDBConnect.get_connect().admin.command("ping")
            ver = MongoDBConnect.get_connect().server_info()["version"]
            return True, ver
        except Exception as e:
            return False, str(e)

    @staticmethod
    def close():
        if MongoDBConnect._client is not None:
            MongoDBConnect._client.close()
            MongoDBConnect._client = None
            return True
        return False
```

### 两个关键点（报告可写）

**① 密码必须 URL 编码**

`Lab@2026` 里的 `@` 是 URI 的分隔符。不编码会变成：

```
mongodb://libWriter:Lab@2026@127.0.0.1:27017/...
                  ↑ 第一个 @ 被当成密码结束
```

结果解析出错 → `Authentication failed` 或连接超时。

`quote_plus("Lab@2026")` → `Lab%402026`

**② 认证库是 library 不是 admin**

`libWriter` 是在 `library` 库下 `createUser` 的，所以 `authSource=library`。
用 `admin` 会 `Authentication failed`。

## 八、排错清单

| 报错 | 原因 | 解决 |
|---|---|---|
| `Authentication failed` | 密码未编码 / authSource 错 | `quote_plus()` + `authSource=library` |
| `ServerSelectionTimeoutError` | mongod 没启动 / 端口不通 | 检查 `ss -lntp \| grep 27017` |
| `ModuleNotFoundError: pymongo` | 没装驱动 | `pip install --user pymongo -i 阿里云` |
| `WriteError: Cannot perform an update on a time-series` | 时间序列集合不能 update | 已改为 append-only 模式 |
| `EOFError: EOF when reading a line` | 非交互模式下程序要输入 | 用 `python3 main.py 3` 这种带参数的方式 |
| 菜单死循环 | 输入耗尽 | 已修复：空输入自动退出 |
| `UnicodeEncodeError` | 终端编码 | `export LANG=en_US.UTF-8` |
