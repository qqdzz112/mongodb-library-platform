### ⚠️ 开发中遇到的问题（报告素材）

**问题 1：admin 库原本是空的，直接加 --auth 会锁死数据库**

- 检查发现 `admin` 库 `getUsers()` 返回 `[]`
- 若无超管就启用 `--auth`，将**无法执行任何管理操作**，连建账号都做不到
- **解决**：先无认证状态下创建 `itcastAdmin`，再重启加 `--auth`

**问题 2：mongosh 里 `use` 在 `--eval` 中不生效**

- 写 `use("admin"); db.createUser(...)` 时，角色被解析成 `userAdminAnyDatabase@test`
- 报错：`Could not find roles: userAdminAnyDatabase@test`
- **解决**：改用 `db.getSiblingDB("admin").createUser(...)`

**问题 3：db.auth() 默认认证库错误**

- 在 `test` 库执行 `db.auth("libReader","Lab@2026")` → `Authentication failed`
- **原因**：`db.auth()` 用**当前库**做认证库，而账号建在 `library`
- **解决**：用连接串 `mongodb://user:pwd@host/library?authSource=library`

**问题 4：时间序列集合无法 update 已有文档**

```
pymongo.errors.WriteError: Cannot perform an update on a time-series collection
that does not have a metaField (code 72)
```

- **原因**：`borrow_logs` 是时间序列集合且**没有 `metaField`**，MongoDB 禁止对已有文档 update/delete
- **影响**：`return_book()` 和 `mark_overdue()` 原本用 `update_many` 改 status，直接报错
- **解决**：改为 **append-only 模式** —— 归还时追加一条 `status:"已归还"` 的新流水，并记 `origin_id` 关联原记录；同时回补库存
- **意义**：这正好体现了时间序列集合"只追加、少更新"的设计本意，是很好的答辩材料

**问题 5：SSH 传输时 `printf` 的 `\n` 被转义**

- `printf "a\nR20240001\n..."` 经 SSH 传输后，`\n` 变成字面 `n`，导致程序读到空输入
- **解决**：改用本地生成带真实换行的文件 + `scp` 上传 + `<` 重定向

**问题 6：功能 10 误删真实数据**

- 测试时执行"清理零库存"，把《数据结构（C语言版）》(stock=0) 删掉了，books 20→19
- **已恢复**：从 `books.txt` 重新插入该文档
- **当前状态**：books=20、readers=16、borrow_logs=52、category_stats=5（已校验 ISBN 齐全）

### 开发 `shot.sh` 过程中发现并修复的问题

**问题 1：PATH 里有两个手动解压的 MongoDB 8.3.11，遮挡了 rpm 安装的 7.0.45**

- `~/.bashrc` 末尾两行：
  ```
  export PATH=/export/software/mongodb/bin:$PATH
  export PATH=/export/serv/mongodb8/bin:$PATH
  ```
- 导致 `mongod --version` 显示 **8.3.11**，而实际运行的服务器是 **7.0.45**（`/usr/bin/mongod`）
- **修复**：注释掉这两行（已备份 `~/.bashrc.bak`），新登录 shell 后 `which mongod` → `/usr/bin/mongod`
- **排查手段**：`ps -ef | grep [m]ongod`（实际进程）+ `rpm -qf /usr/bin/mongod`（包来源）三者对照
- ⚠️ 报告里务必写 7.0.45，不要写成 8.3.11

**问题 2：`itcastAdmin` 缺少监控权限**

- `getCmdLineOpts`、`getLog` 报 `not authorized on admin`
- **原因**：初始只给了 `userAdminAnyDatabase` / `readWriteAnyDatabase` / `dbAdminAnyDatabase`，不含 `clusterMonitor` / `hostManager`
- **修复**：`db.grantRolesToUser("itcastAdmin", ["clusterMonitor","hostManager"])`

**问题 3：`$sortByCount` 返回的游标不支持 `.limit()`

```
TypeError: db.books.aggregate(...).limit is not a function
```

- **原因**：mongosh 中 `aggregate()` 返回游标，不能在 shell 里链式接 `.limit()`
- **修复**：改为 `.toArray()` 后再用 `slice(0,3)`

**问题 4：`source ~/.bashrc` 无法移除已注入的 PATH**

- 修改 `~/.bashrc` 后 `source` 只是再追加一次，旧路径仍在 `$PATH` 中
- **修复**：需 `exit` 后重新登录，或用 `bash -l` 开新登录 shell
