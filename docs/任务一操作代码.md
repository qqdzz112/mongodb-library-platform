## S1-01 数据目录与启动命令

### 操作代码

```bash
# 1. 创建自定义数据目录和日志目录
sudo mkdir -p /export/servers/mongodb/data
sudo mkdir -p /export/servers/mongodb/log

# 2. 把目录属主改为 mongod 用户（重要！否则启动会报权限错误）
sudo chown -R mongod:mongod /export/servers/mongodb

# 3. 确认目录已建好
ls -ld /export/servers/mongodb/data
ls -ld /export/servers/mongodb/log
```

**期望输出**

```
drwxr-xr-x. 4 mongod mongod 4096 Oct 21 23:09 /export/servers/mongodb/data
drwxr-xr-x. 3 mongod mongod 4096 Oct 21 22:00 /export/servers/mongodb/log
```

### 启动命令（完整）

```bash
sudo mongod \
  --dbpath /export/servers/mongodb/data \
  --port 27017 \
  --logpath /export/servers/mongodb/log/mongod.log \
  --fork --auth --bind_ip_all
```

**参数逐个说明**

| 参数 | 作用 |
|---|---|
| `--dbpath` | **指定自定义数据目录**（任务书 ST-1.1 的核心要求） |
| `--port` | 监听端口 27017 |
| `--logpath` | 日志文件路径 |
| `--fork` | 后台运行（父进程退出，子进程继续） |
| `--auth` | 启用访问控制（任务四 S3 需要） |
| `--bind_ip_all` | 监听所有网卡（宿主机 Compass 要连） |

**期望输出**

```
about to fork child process, waiting until server is ready for connections.
forked process: 18033
child process started successfully, parent exiting
```

```bash
/usr/bin/mongosh

$ mongod --version
db version v7.0.45
Build Info: {
    "version": "7.0.45",
    "gitVersion": "a52313e13ab55c9bddf7c3ff91dab286fa381796",
    "openSSLVersion": "OpenSSL 3.5.8",
    "modules": [],

$ mongosh --version

$ rpm -qf /usr/bin/mongod
mongodb-org-server-7.0.45-1.el9.x86_64
```

### ⚠️ 这一步踩过的坑（重点写进报告）

**问题**：`mongod --version` 显示 **8.3.11**，但服务实际是 **7.0.45**。

**原因**：虚拟机里有三份 mongod：

| 路径 | 版本 | 来源 |
|---|---|---|
| `/export/serv/mongodb8/bin/mongod` | 8.3.11 | 手动解压 |
| `/export/software/mongodb/bin/mongod` | 8.3.11 | 手动解压 |
| `/usr/bin/mongod` | **7.0.45** | **rpm 安装（实际在用）** |

`~/.bashrc` 末尾有两行把 8.3.11 放到了 PATH 最前面：

```bash
export PATH=/export/software/mongodb/bin:$PATH
export PATH=/export/serv/mongodb8/bin:$PATH
```

**排查过程**

```bash
# 1. 看实际运行的进程是哪个
ps -ef | grep [m]ongod | head -3

# 2. 看 rpm 装的是哪个
rpm -qf /usr/bin/mongod

# 3. 看命令解析到哪
which mongod      # 显示 /export/serv/mongodb8/bin/mongod（错的）
type -a mongod    # 列出所有同名命令

# 4. 直接跑绝对路径对比
/usr/bin/mongod --version          # 7.0.45
/export/serv/mongodb8/bin/mongod --version   # 8.3.11
```

**修复**

```bash
# 备份
cp ~/.bashrc ~/.bashrc.bak

# 注释掉两行
sed -i 's|^export PATH=/export/software/mongodb/bin|# &|' ~/.bashrc
sed -i 's|^export PATH=/export/serv/mongodb8/bin|# &|' ~/.bashrc

# 验证修改
tail -5 ~/.bashrc
```

**⚠️ 关键**：`source ~/.bashrc` **不会生效**！因为它只是再追加一次 PATH，旧路径仍在 `$PATH` 里。必须：

```bash
exit          # 退出当前会话
# 重新登录
```

或者开新的登录 shell：

```bash
bash -l
```

**验证**

```bash
which mongod          # /usr/bin/mongod
mongod --version      # db version v7.0.45
```

> **报告里这么写**：「环境中存在多个 MongoDB 版本导致命令与运行服务不一致，
> 通过 `ps -ef` 与 `rpm -qf` 定位到实际服务为 rpm 安装的 7.0.45，
> 修正 PATH 后版本统一。」

### 环境变量配置（如果需要配 PATH）

**方式一：系统级**（所有用户生效）

```bash
sudo tee /etc/profile.d/mongodb.sh > /dev/null << 'EOF'
export PATH=$PATH:/usr/bin
EOF

# 使生效
source /etc/profile.d/mongodb.sh
```

**方式二：用户级**

```bash
echo 'export PATH=$PATH:/usr/bin' >> ~/.bashrc
bash -l
```

> 因为 rpm 装的 mongod 本来就在 `/usr/bin`（天然在 PATH 里），所以其实**不需要额外配置**。
> 任务书要求「将 MongoDB 可执行文件目录加入系统环境变量，验证新开终端可直接执行」——
> rpm 安装已完成这一步，截图证明「新终端可直接调用」即可。

### ⚠️ 权限坑

`getCmdLineOpts` 需要 **clusterMonitor** 或 **hostManager** 角色。
最初 `itcastAdmin` 只有三个 AnyDatabase 角色，执行会报：

```
MongoServerError: not authorized on admin to execute command { getCmdLineOpts: 1 }
```

**修复**

```javascript
mongosh "mongodb://itcastAdmin:Lab%402026@127.0.0.1:27017/admin?authSource=admin"

db.grantRolesToUser("itcastAdmin", ["clusterMonitor", "hostManager"])

// 验证
db.getUser("itcastAdmin")
```

## 排错清单

| 报错 | 原因 | 解决 |
|---|---|---|
| `权限不够`（写 /etc/yum.repos.d） | 普通用户 | `sudo -i` 切 root |
| `child process failed, exited with 1` | 数据目录不存在 | `mkdir -p` 建目录 |
| `Permission denied` 写数据目录 | 属主不是 mongod | `chown -R mongod:mongod` |
| `not authorized on admin` | 账号缺角色 | 补 `clusterMonitor`、`hostManager` |
| `command not found: mongod` | PATH 没生效 | `hash -r` 或重新登录 |
| `mongod --version` 版本不对 | 多版本 PATH 冲突 | 注释 `~/.bashrc` 里的旧路径，**重新登录** |
| `source ~/.bashrc` 后仍不对 | 旧路径还在 `$PATH` | 必须 `exit` 重新登录 |
| `Address already in use` | 端口被占 | `sudo pkill mongod` 后重启 |
