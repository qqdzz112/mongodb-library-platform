## 执行顺序（重要）

```
任务一：启动服务
   ↓
任务二：建 6 个集合 + 导入数据（books 20 / readers 16 / borrow_logs 66）
   ↓
任务三：① Q1—Q16 全部查询（记录基线条数）
        ② U1—U4 更新（会改变 Q1/Q2/Q11/Q12 的结果）
        ③ D1—D3 删除（borrow_logs 66 → 52）
   ↓
任务四：① A1—A9 聚合
        ② I1—I5 建索引 + explain
        ③ S1—S2 建账号（在启用 --auth 之前！）
        ④ S3 重启加 --auth → 权限验证
   ↓
任务五：PyMongo 程序（连接串要带账号密码）
   ↓
任务六：Compass 验收 + 导出
```

**为什么顺序不能乱**：

| 操作 | 影响 |
|---|---|
| U2 改价格 | Q1（price>80）的条数可能变 |
| U4 删 tags | Q11 从 12 变 11、Q12 从 17 变 16 |
| D1/D2 删流水 | A6 借阅趋势的年份数字变小 |
| S3 加 --auth | 之后所有连接都要账号 |

## 截图技巧

**1. 一次命令拍多行**

把相关命令写在同一个终端窗口里连续执行，这样一张图能拍到命令 + 多条结果。

**2. 让终端全屏**

`Ctrl + Shift + F` 或直接最大化 FinalShell 窗口，避免输出被截断。

**3. 清屏**

每张截图前按 `Ctrl + L` 清屏，避免带上一节残留的输出。

**4. 提示符要入镜**

终端提示符（`liuhuiping@nosql01:~$` 或 `root@nosql01:~#`）能证明是在你自己的虚拟机里执行的。

**5. 截图工具**

`Win + Shift + S` → 拖动选区 → 自动复制 → 粘贴到文件夹或直接 `Ctrl + S` 保存。
