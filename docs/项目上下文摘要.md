## 六、关键踩坑（报告素材）

1. **时间序列不能 update**：无 `metaField` 时对已有文档 update 报 code 72 → 改 append-only
2. **2 年过期会删数据**：`expireAfterSeconds: 63072000` 会清掉 2023 年数据 → `collMod` 改 315360000（10年）
3. **admin 库为空时加 --auth 会锁死** → 先建 itcastAdmin
4. **Q14 并列**：4.7 分有 3 本 → 加 `borrow_count` 次序键
5. **多版本 PATH 冲突**：`~/.bashrc` 里两个 8.3.11 遮挡了 7.0.45 → 注释掉后**必须重新登录**
6. **`$unset` 对不存在字段静默成功**：`modifiedCount: 0` 不报错
7. **13 条"逾期"全带 return_date**：实为"逾期后已归还" → 按 status 删
8. **EJSON.parse 必须用**：`JSON.parse` 会让 `{"$date":...}` 变字符串，时序集合插入报错
