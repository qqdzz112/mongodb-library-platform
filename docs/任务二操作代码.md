## S2-03 时间序列集合 borrow_logs（重点）

### 操作代码

```javascript
// 建时间序列集合
db.createCollection("borrow_logs", {
  timeseries: {
    timeField: "borrow_date",   // 时间字段名（必须是 Date 类型）
    granularity: "hours"        // 时间粒度
  },
  expireAfterSeconds: 63072000  // 2 年后自动过期（任务书要求）
})

// 查看配置
db.getCollectionInfos({name: "borrow_logs"})
```

### 期望输出

```javascript
{ ok: 1 }
[
  {
    name: 'borrow_logs',
    type: 'timeseries',
    options: {
      expireAfterSeconds: Long("63072000"),
      timeseries: {
        timeField: 'borrow_date',
        granularity: 'hours',
        bucketMaxSpanSeconds: 2592000
      }
    }
  }
]
```

### ⚠️ 关键坑：这个过期窗口会吃掉你的数据

任务书要求 `expireAfterSeconds: 63072000`（= 2 年）。但：

| 项 | 值 |
|---|---|
| 当前系统时间 | **2026-10-21** |
| 2 年窗口起点 | **2024-10-21** |
| 数据集最早记录 | **2023-01-08** |

结论：**2023 全年 + 2024 前 10 个月的借阅流水会被判为过期并自动删除**，A6 借阅趋势里的「2023年 15 条」会直接消失。

### 处理步骤（先截图，再改）

```javascript
// 第 1 步：按任务书原值建（截 S2-03 用）
// 第 2 步：截图完成后，立刻调大窗口
db.runCommand({
  collMod: "borrow_logs",
  expireAfterSeconds: 315360000   // 10 年
})

// 第 3 步：确认已改
db.getCollectionInfos({name: "borrow_logs"})
// options.expireAfterSeconds 应变成 Long("315360000")
```

> 这段「发现过期风险 → 截图留证 → 调大窗口 → 复验」的完整过程，
> 直接可以写进报告的「问题与核对」章节。

### 📸 截图 `task2_timeseries_borrow_logs.png`

| 必须拍到 | 说明 |
|---|---|
| `type: 'timeseries'` | 证明是时间序列 |
| `timeField: 'borrow_date'` | 时间字段 |
| `granularity: 'hours'` | 粒度 |
| `expireAfterSeconds: Long("63072000")` | 过期时间 |

## 附：原始数据导入的完整代码（备查）

如果要从零重新导入一遍，完整流程：

```javascript
// 前提：数据集已放在 /export/dataset/
const fs = require("fs");

// EJSON.parse 会把 {"$date":"..."} 还原成真正的 Date 类型
// 这一步是时间序列集合能插入的前提
function loadJson(path){
  return EJSON.parse(fs.readFileSync(path, "utf8"));
}

// --- books：先单条，再批量 ---
var books = loadJson("/export/dataset/books.txt");
var first = books.shift();          // 取出第一条
db.books.insertOne(first);          // insertOne
db.books.insertMany(books);         // insertMany 其余 19 条

// --- readers ---
var readers = loadJson("/export/dataset/readers.txt");
db.readers.insertMany(readers);     // 16 条

// --- borrow_logs（时间序列，必须是 Date）---
var logs = loadJson("/export/dataset/borrow_logs.txt");
db.borrow_logs.insertMany(logs);    // 66 条
```

### ⚠️ 为什么必须用 EJSON.parse

| 写法 | `{"$date":"2023-04-01..."}` 的结果 | 能否插入时序集合 |
|---|---|---|
| `JSON.parse` | 普通对象 `{ $date: "2023-04-01..." }` | ❌ 报 `timeField must be a Date` |
| `EJSON.parse` | 真正的 `ISODate("2023-04-01...")` | ✅ 成功 |

## 排错清单

| 报错 | 原因 | 解决 |
|---|---|---|
| `Authentication failed` | 密码未编码 / 认证库错 | 密码写 `Lab%402026`，`authSource=library` |
| `NamespaceExists` | 集合已存在 | `db.xxx.drop()` 或换名 |
| `timeField must be a Date` | 传了字符串 | 用 `EJSON.parse()` |
| `cannot insert into a view` | 往视图写数据 | 视图只读，改往 `books` 写 |
| `not authorized on library` | 用了只读账号做写操作 | 换成 `libWriter` |
| `Command aggregate requires authentication` | 没带账号连接 | 用完整连接串 |
